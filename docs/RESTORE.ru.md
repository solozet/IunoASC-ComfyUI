# Восстановление сессии IunoASC

[README](../README.ru.md) · [English](RESTORE.md)

## Сохранение

1. Открой **Результаты · 8083**.
2. Отметь результаты для архива. Включи **Включить входные файлы**, если нужны исходные изображения или другие входные медиа.
3. Нажми **Сохранить сессию · ZIP** и дождись завершения скачивания в браузере.

| Папка / файл архива | Содержимое |
| --- | --- |
| `workflows/` | Сохранённые воркфлоу ComfyUI |
| `settings/comfy.settings.json` | Настройки интерфейса, если доступны |
| `inputs/` | Входные файлы, если выбраны |
| `outputs/` | Отмеченные результаты |
| `session.json` | Список файлов и версии компонентов |

Веса моделей, пакеты кастомных нод, HF-токены и конфигурация Manager не входят в архив.

## Восстановление на новом Pod

1. Запусти IunoASC, установи те же веса пресета и кастомные ноды. После установки Spectrum перезапусти ComfyUI через Manager.
2. Распакуй ZIP сессии на своём компьютере.
3. Загрузи содержимое архива в соответствующие папки на Pod. Перед заменой проверь существующие файлы и сохрани копию текущих настроек интерфейса.

| Источник в архиве | Путь назначения на Pod |
| --- | --- |
| Содержимое `workflows/` | `/opt/ComfyUI/user/default/workflows/` |
| Содержимое `inputs/` | `/data/inputs/` |
| Содержимое `outputs/` | `/data/outputs/` |
| `settings/comfy.settings.json` | `/opt/ComfyUI/user/default/comfy.settings.json` |

4. Обнови ComfyUI, открой восстановленный воркфлоу и проверь выбранные имена моделей и входных файлов.

Воркфлоу и настройки восстанавливаются вручную. Версии исходных компонентов можно посмотреть в `session.json`.

## Резервная копия в браузере

Страница результатов отдельно сохраняет локальные копии outputs. Если Pod недоступен, используй красную кнопку или список сохранённых файлов на той же странице. Эти копии не содержат воркфлоу и настроек интерфейса.
