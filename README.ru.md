# IunoASC ComfyUI

[English](README.md) · [Русский](README.ru.md) · [Docker Hub](https://hub.docker.com/r/solozeet/comfyui/tags) · [Статус сборок](https://github.com/solozet/IunoASC-ComfyUI/actions/workflows/build.yml)

ComfyUI для RunPod с пресетами MiniMax H3, классическим Manager, установкой моделей, мониторингом ресурсов и видеогалереей. Веса скачиваются по мере необходимости.

## Быстрый запуск

| Поле шаблона RunPod | Значение |
| --- | --- |
| Container image | **`solozeet/comfyui:cu130`** |
| Start Command | **Оставить пустым** |
| HTTP ports | **`3000,8081,8082,8083`** |
| Container Disk | Рекомендуется **150 GB** для образа, весов и результатов |
| Обязательные переменные окружения | **Нет** |
| Логин / пароль | **Нет** |

1. Запусти Pod. Дождись в логах `[IunoASC] GPU preflight passed` и сообщения о готовности ComfyUI.
2. Открой **Модели и пресеты · 8081**, выбери пресет и нажми **Установить пресет**.
3. После установки Spectrum для LightSpeed или экспериментального пресета перезапусти **ComfyUI через Manager**.
4. Нажми **Открыть в ComfyUI** или выбери **Workflows → IunoASC**. Загрузи референс, введи промпт и запусти генерацию.
5. Открой **Результаты · 8083**, чтобы посмотреть видео, скачать файлы и сохранить сессию.

Воркфлоу доступны в папке IunoASC с первого запуска. Установка пресета скачивает недостающие веса и необходимый пакет кастомных нод; существующие правки воркфлоу и установленный Spectrum сохраняются. Прогресс скачивания закреплён внизу экрана при прокрутке. После ошибки повтори скачивание — завершённые файлы используются повторно.

## Интерфейсы

| HTTP-порт | Интерфейс | Возможности |
| --- | --- | --- |
| **3000** | ComfyUI | Генерация H3, воркфлоу, классический Manager |
| **8081** | Модели и пресеты | Установка пресетов, сворачиваемые списки весов, скачивание с Hugging Face, панель прогресса |
| **8082** | Панель управления | GPU/CPU, RAM/VRAM, swap, датчики, графики, диск, версии и очередь ComfyUI |
| **8083** | Результаты | Видеогалерея, просмотр, скачивание файлов, ZIP сессии и резервные копии в браузере |

Панели поддерживают **английский, русский, немецкий, французский, упрощённый китайский и японский**. Переключатель языка находится слева от ссылок навигации; выбор сохраняется в браузере и переносится между панелями.

У каждого порта свой HTTPS-адрес: `https://POD_ID-PORT.proxy.runpod.net/`. **Авторизации нет: любой, кто получил доступ к этим адресам, может пользоваться сервисами.** Если прямая ссылка ComfyUI из RunPod возвращает HTTP 403, попробуй **ComfyUI ↗** в одной из панелей. Проверка источника запроса не является защитой паролем.

## Основные пресеты

| | Официальный MiniMax H3 I2V | **LightSpeed H3** |
| --- | --- | --- |
| Воркфлоу | Адаптированный I2V-пример Comfy Org | Компактный подграф с настройками видео и LoRA |
| Диффузионная модель | FL2VA INT8 ConvRot; FP8 scaled в cu128 | FL2VA INT8 ConvRot |
| Текстовый энкодер | Qwen3-VL 32B NVFP4 AWQ | Тот же энкодер |
| Video VAE | FP16 | **INT8 ConvRot** |
| Audio VAE | FP32 | Тот же Audio VAE |
| LoRA | Официальная Turbo на 8 шагов | Turbo v4 + дополнительная пользовательская LoRA |
| Пакет кастомных нод, устанавливаемый с пресетом | Нет | **Spectrum MiniMax H3** |
| Шаги по умолчанию | 8 | **5** |
| Файлы весов | 5 | 5 |
| Размер весов | **44,43 GB** с INT8; **44,41 GB** с FP8 | **40,69 GB** |

Размеры указаны в десятичных GB и относятся только к весам. Если официальный пресет cu130 уже установлен, LightSpeed скачает ещё **3,43 GB**: INT8 Video VAE и Turbo v4 LoRA. Два основных пресета вместе занимают **47,86 GB**. Официальный пресет cu128 использует отдельный файл диффузионной модели.

### LightSpeed H3 — источник и веса

Создан на основе **[MiniMax H3 Ultra Fastest True 4 Steps + HD Sound | 6GB VRAM 16GB RAM [V8 Update] Lightning Speed](https://civitai.com/models/2835250?modelVersionId=3305336)** от **[RedditUser9811](https://civitai.com/user/RedditUser9811)**.

| Файл весов | Папка моделей ComfyUI | Размер |
| --- | --- | ---: |
| `minimax_h3_fl2va_pruned_int8_convrot.safetensors` | `diffusion_models` | 20,97 GB |
| `qwen3vl_32b_minimax_h3_nvfp4_awq.safetensors` | `text_encoders` | 15,69 GB |
| `minimax_h3_video_vae_int8_convrot.safetensors` | `vae` | 2,81 GB |
| `minimax_h3_audio_vae_fp32.safetensors` | `vae` | 0,61 GB |
| `minimax_h3_turbo_v4_step600_ema_pruned_comfyui.safetensors` | `loras` | 0,62 GB |

Первые четыре файла скачиваются из [Comfy-Org/MiniMax-H3](https://huggingface.co/Comfy-Org/MiniMax-H3), Turbo v4 — из [drbaph/MiniMax-H3-Turbo-Lora-ComfyUI](https://huggingface.co/drbaph/MiniMax-H3-Turbo-Lora-ComfyUI). Установщик также добавляет [Spectrum MiniMax H3](https://github.com/xmarre/ComfyUI-Spectrum-MiniMax-H3).

### Настройки LightSpeed

| Настройка | Значение по умолчанию / поведение |
| --- | --- |
| Промпт | Пустой; редактируется в компактной ноде |
| Разрешение | 9:16, 2 MP, кратность 32; соотношение сторон и размеры на основном холсте |
| Длительность / шаги | **5 секунд / 5 шагов** |
| FPS | **24**; также определяет поддерживаемое число кадров |
| Цвет / глубина | **HDR / 10 бит**; можно выбрать SDR и другую поддерживаемую глубину |
| Turbo v4 LoRA | **Включена, сила 1,0** |
| Дополнительная LoRA | **Выключена**; отдельный выбор файла, переключатель и сила |
| Spectrum | Включён; подробные настройки внутри подграфа |
| Шум | Внутри подграфа; **randomize** |
| Reference 1 | Включён и развёрнут; загрузи своё изображение |
| References 2–6 | Свёрнуты и bypassed |
| Памятка по разрешениям | На основном холсте |

В дополнительной LoRA изначально выбран установленный Turbo-файл как заполнитель. Пустой выбор также работает, когда дополнительная LoRA выключена.

## Скачивание собственных весов

Вставь `автор/репозиторий`, ссылку на репозиторий Hugging Face или ссылку на файл с `blob`/`resolve`. Нажми **Найти файлы**, выбери файл и тип назначения, затем **Скачать вес**. Прямая ссылка автоматически выбирает нужный файл. Для репозитория с ограниченным доступом можно указать HF-токен.

| Выбранный тип | Папка назначения |
| --- | --- |
| LoRA — по умолчанию | `models/loras` |
| Диффузионная модель | `models/diffusion_models` |
| Текстовый энкодер | `models/text_encoders` |
| VAE | `models/vae` |

Файлы сохраняются под своим именем без исходных подпапок. **Существующий непустой файл с таким же именем используется повторно, даже если репозиторий другой.** При скачивании пресетов дополнительно проверяется ожидаемый размер файла. После загрузки обнови списки моделей ComfyUI и выбери файл в соответствующем загрузчике.

## Панель управления

Показатели обновляются каждые **5 секунд**. Графики отображают последние **5 минут, пока страница открыта**.

| Область | Показатели |
| --- | --- |
| GPU | Название, драйвер, загрузка, занятая/общая VRAM, температура, потребление/лимит мощности и частота |
| CPU | Загрузка, доступные ядра, температура и потребление при доступных датчиках хоста |
| Память | Занятая/общая RAM, файловый кэш и swap |
| ComfyUI | Доступность, выполняемые задания и очередь |
| Диск | Занятое, свободное и общее место |
| ПО | Версии ComfyUI, Manager, Kitchen, PyTorch и CUDA контейнера/PyTorch |
| Графики | Загрузка GPU/CPU, использование RAM/VRAM, температура и потребление GPU |
| Предупреждения | RAM ≥ 90%, VRAM ≥ 95%, GPU ≥ 85 °C, свободное место < 10% |

Показатели CPU и памяти отмечены как **Контейнер** или **Хост**; данные хоста могут включать другие нагрузки. Использование RAM включает файловый кэш. Прочерк означает недоступный датчик. Время работы относится к сервису контрольной панели.

## Результаты и резервное копирование

Список файлов обновляется каждые **3 секунды** без перезагрузки страницы и прерывания видео.

| Действие | Результат |
| --- | --- |
| Предпросмотр | Просмотр видео прямо на странице |
| Информация о видео | Разрешение, FPS, кодек, глубина цвета и цветовые метаданные |
| Скачать файл / ZIP результатов | Отдельный файл или все результаты |
| Сохранить сессию · ZIP | Воркфлоу, настройки интерфейса, выбранные входные файлы, отмеченные результаты и версии компонентов |
| Резервная копия в браузере | Копирование результатов в браузер; количество, размер и прогресс сохранения |
| Красная кнопка | Скачивание сохранённых копий даже при недоступном Pod |

**Сохранение сессии** не включает веса моделей, HF-токены и конфигурацию Manager. Отметь нужные результаты и нажми **Сохранить сессию · ZIP**. Для восстановления используй [инструкцию](docs/RESTORE.ru.md).

Для воспроизведения HDR нужны совместимые браузер, кодек и экран. Если предпросмотр не воспроизводится, скачай оригинальный файл.

### Резервная копия в браузере — аварийное скачивание

Держи страницу результатов открытой, пока Pod работает, и дождись появления файлов в списке **сохранённых в браузере**. **После удаления Pod можно скачать только копии, уже полностью сохранённые локально.** Автоматическое копирование можно отключить переключателем.

| Особенность | Поведение |
| --- | --- |
| Локальное хранилище | Используется место на диске твоего компьютера |
| Привязка | Конкретный адрес Pod и профиль браузера |
| Большой ZIP в Chrome/Edge | Запись прямо в выбранный файл, если доступен системный диалог сохранения |
| Другие браузеры | ZIP в памяти до **512 MiB**; сохранённые файлы можно скачивать по одному |
| Очистка данных сайта / приватный режим / вытеснение браузером | Могут удалить сохранённые копии |
| Фоновая вкладка | Обновление и копирование могут замедлиться |

Резервная копия в браузере содержит результаты. Для сохранения воркфлоу и настроек используй **Сохранить сессию · ZIP**.

## Варианты образов и версии

| Суффикс образа | CUDA базы NVIDIA | PyTorch | Attention / модель официального пресета | Драйвер по требованиям образа |
| --- | --- | --- | --- | --- |
| **`cu130`** | **13.0.2** | **2.9.1+cu130** | Comfy Kitchen / INT8 ConvRot | ≥ 580.95.05 |
| `cu128` | 12.8.1 | 2.9.1+cu128 | Стандартный / FP8 scaled | ≥ 570.124.06 |
| `cu131` | 13.1.1 | 2.9.1+cu130 | Comfy Kitchen / INT8 ConvRot | ≥ 590.48.01 |
| `cu132` | 13.2.0 | 2.9.1+cu130 | Comfy Kitchen / INT8 ConvRot | ≥ 595.45.04 |

Используй `solozeet/comfyui:<суффикс>`. **cu131 и cu132 — экспериментальные варианты базы; оба используют PyTorch CUDA 13.0.** Пороги драйверов — консервативная политика проверки при запуске этого проекта; [технические подробности](docs/DEVELOPMENT.md#driver-policy). LightSpeed и Light VAE сохраняют настройки INT8/Kitchen; их **совместимость с cu128 не проверена**.

Теги версий вроде `comfy0.39.0-cu130` и короткие теги обновляются при пересборке. Чтобы закрепить конкретную сборку, используй digest образа.

| Компонент | Включённая версия |
| --- | --- |
| ComfyUI | **0.39.0** |
| ComfyUI Manager | **4.3**, классический интерфейс |
| Comfy Kitchen | **0.2.37** |
| PyTorch / torchvision / torchaudio | **2.9.1 / 0.24.1 / 2.9.1** |

## Хранение данных и ошибки запуска

| Данные | Путь на Pod |
| --- | --- |
| Модели | `/data/models` |
| Входные файлы | `/data/inputs` |
| Результаты | `/data/outputs` |
| Воркфлоу | `/opt/ComfyUI/user/default/workflows/IunoASC` |

**Сборка использует временный Container Disk. Перед удалением или миграцией Pod сохрани результаты и свои изменения.** HF-токены, введённые в загрузчике, не сохраняются в конфигурации.

При запуске preflight проверяет драйвер, CUDA и небольшие операции на GPU, затем запускает сервисы. **Если проверка завершается ошибкой, контейнер останавливается, но оплачиваемый Pod продолжает существовать. Сохрани логи и самостоятельно останови проблемный Pod.** Проблемы драйвера хоста и самого GPU решаются с провайдером инфраструктуры.

Сборки образов и автоматические проверки последней версии прошли успешно. Полная генерация H3 в последних образах пока не проверена на GPU.
